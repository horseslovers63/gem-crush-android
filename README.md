Gem Crush Android build starter

Package ID: com.gemcrush.game
Build: GitHub Actions -> Build Gem Crush APK
Output artifact: Gem-Crush-APK / app-debug.apk

How to use:
1. Create a GitHub repository and upload all files/folders from this ZIP.
2. Open the repository's Actions tab.
3. Select "Build Gem Crush APK", then "Run workflow" (or push to main).
4. Wait for the green successful run.
5. Open that run, scroll to Artifacts, and download "Gem-Crush-APK".
6. Extract the ZIP and install app-debug.apk on Android. If prompted, allow installs from this source.

Important:
- This package contains a playable starter implementation of Gem Crush.
- If you want the APK to contain your exact previously edited HTML game, replace www/index.html with that final HTML file before building.
- A debug APK is suitable for testing and direct installation. Google Play release requires a signed release build.
